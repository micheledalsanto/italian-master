# Calchi dall'inglese, falsi amici, anglicismi

Chi scrive partendo dall'inglese, persona o modello, lascia impronte. Questo file serve a riconoscerle. La regola generale: non chiederti «come si traduce questa frase?», chiediti «che cosa direbbe un italiano in questa situazione?».

## 2. Falsi amici

Parole che somigliano a una parola inglese e vogliono dire altro. Nella colonna centrale il significato che hanno davvero in italiano.

| Italiano | Significa | Per l'inglese usa |
| --- | --- | --- |
| attualmente | adesso | *actually* → in realtà, veramente, anzi |
| eventualmente | nel caso, se capita | *eventually* → alla fine, prima o poi |
| definitivamente | per sempre, in modo definitivo | *definitely* → di sicuro, senz'altro, certo |
| possibilmente | se possibile | *possibly* → forse, può darsi |
| ultimamente | di recente | *ultimately* → in definitiva, alla fine |
| consistente | sostanzioso, notevole | *consistent* → coerente, costante, uniforme |
| comprensivo | che capisce, indulgente; che comprende | *comprehensive* → completo, esauriente |
| sensibile | che sente molto | *sensible* → ragionevole, sensato |
| educazione | buone maniere | *education* → istruzione, formazione, scuola |
| evidenza | l'essere evidente | *evidence* → prove, dati, indizi |
| argomento | tema; ragionamento | *argument* (lite) → discussione, litigio |
| severo | rigoroso, duro (di persone) | *severe* → grave, forte (una malattia grave) |
| drammatico | da dramma, tragico | *dramatic* → netto, drastico, spettacolare |
| confidente | persona a cui ci si confida | *confident* → sicuro, fiducioso |
| eccitato | ha una sfumatura sessuale o nervosa | *excited* → entusiasta, contento, emozionato |
| pretendere | esigere | *pretend* → fingere |
| annoiare | dare noia, tediare | *annoy* → infastidire, seccare |
| attitudine | predisposizione, talento | *attitude* → atteggiamento |
| confrontare | paragonare | *confront* → affrontare |
| occorrere | servire, essere necessario | *occur* → succedere, capitare, venire in mente |
| suggestione | fascino, influsso | *suggestion* → suggerimento, proposta |
| triviale | volgare | *trivial* → banale, di poco conto |
| morbido | soffice | *morbid* → morboso |
| libreria | negozio o mobile | *library* → biblioteca |
| fattoria | azienda agricola | *factory* → fabbrica |
| parenti | tutti i familiari | *parents* → genitori |
| rumore | suono sgradevole | *rumor* → voce, diceria |
| domestico | di casa | *domestic* (voli, mercato) → nazionale, interno |
| basico | termine della chimica | *basic* → di base, elementare, semplice |
| assumere | prendere (un incarico, un farmaco), dare lavoro | *assume* → supporre, presumere, dare per scontato |
| realizzare | fare, costruire | *realize* → rendersi conto, capire, accorgersi |
| supportare | reggere (tecnico); si è diffuso per sostenere | *support* → sostenere, appoggiare, aiutare, assistere |
| processare | sottoporre a processo | *process* → elaborare, trattare, lavorare |
| applicare | mettere sopra, mettere in pratica | *apply for* → fare domanda, candidarsi |
| introdurre | far entrare, avviare | *introduce* (una persona) → presentare |
| salvare | mettere in salvo, registrare un file | *save* (tempo, soldi) → risparmiare |
| spendere | spendere denaro | *spend time* → passare, dedicare, impiegare tempo |
| rilevante | notevole, importante | *relevant* → pertinente, che riguarda |
| convenzionale | conforme a una convenzione | spesso meglio tradizionale, solito |
| sofisticato | raffinato, ricercato; artefatto | *sophisticated* (tecnologia) → avanzato, complesso |
| locale | del luogo; un bar | *location* → posto, sede, luogo |
| ingaggiare | assumere a contratto, dare inizio (a una battaglia) | *engage* → coinvolgere |
| indirizzare | dare una direzione | *address* (un problema) → affrontare |
| disegnare | fare un disegno | *design* → progettare, ideare |
| consegnare | dare in mano | *deliver* (risultati, valore) → dare, ottenere, portare |
| guidare | condurre un veicolo, una squadra | *drive* (la crescita) → spingere, trainare, far crescere |
| finalmente | esprime sollievo dopo un'attesa | *finally* (in un elenco) → infine, per ultimo |
| largo | ampio in larghezza | *large* → grande |
| preservativo | profilattico | *preservative* → conservante |
| patente | licenza di guida | *patent* → brevetto |
| editore | chi pubblica | *editor* → redattore, curatore, direttore |
| moroso | chi è in ritardo con i pagamenti | *morose* → imbronciato, cupo |

Alcuni di questi usi «all'inglese» sono ormai registrati dai dizionari: «realizzare» per accorgersi, «supportare» per sostenere, «assumere» per presumere. Non sono errori. Restano però un segnale quando si sommano, e l'alternativa tradizionale è quasi sempre più precisa.

## 4. Anglicismi: quando tenerli

L'italiano contemporaneo usa molte parole inglesi, e togliere tutto sarebbe innaturale quanto abusarne. Criterio pratico:

**Tieni l'anglicismo** quando è il nome normale della cosa, quello che userebbe il lettore: computer, mouse, sport, film, weekend, email, smartphone, app, web, online, link, password, marketing, budget, manager, leader, test, bar, hobby, jeans, stress, podcast, streaming, startup, software, hardware.

**Preferisci l'italiano** quando esiste, è comune e non suona forzato:

| Anglicismo | Italiano |
| --- | --- |
| meeting, call | riunione, telefonata, chiamata |
| deadline | scadenza |
| feedback | riscontro, parere, commenti |
| team | squadra, gruppo |
| mission, vision | scopo, obiettivo, idea |
| know-how | competenze, esperienza |
| step | passo, fase, passaggio |
| trend | tendenza |
| skill | competenza, capacità |
| brand | marchio, marca |
| target | pubblico, destinatari, obiettivo |
| location | posto, sede, luogo |
| competitor | concorrente |
| customer care | assistenza clienti |
| performance | prestazioni, risultati, rendimento |
| report | rapporto, relazione, resoconto |
| briefing, recap | riunione, riepilogo |
| planning | programma, pianificazione |
| asset | risorsa, bene |
| mood | atmosfera, umore |
| food | cibo |
| ticket | biglietto, richiesta di assistenza |
| workshop | laboratorio, seminario |
| best practice | buone pratiche |
| smart working | lavoro da casa, lavoro agile, lavoro da remoto |
| lockdown, green pass, spending review | restano come nomi propri di fatti storici |

**Evita i verbi ibridi** fuori dal gergo di un ufficio: schedulare (fissare, programmare), forwardare (inoltrare), brieffare (dare istruzioni), matchare (far combaciare), switchare (passare), performare (rendere, andare bene), deliverare (consegnare), skippare (saltare), settare (impostare), sharare (condividere), uploadare (caricare), killare, flaggare (segnare). «Cliccare», «chattare», «taggare», «googlare», «postare», «scrollare», «spoilerare» sono invece entrati nell'uso.

**Guarda il pubblico.** In un testo per sviluppatori «deploy», «commit» e «bug» non si traducono, e in un portfolio di design restano «landing page», «hero section», «call to action», «brand», «claim», «packaging», «layer», «design token». In un avviso del Comune «form», «slot» e «hub» si traducono. La tabella qui sopra vale per i testi rivolti a tutti: quando si scrive per chi fa un mestiere, si usano le parole che in quel mestiere si dicono, e tradurle fa sembrare estraneo chi scrive. I criteri per decidere sono in `descrivere-e-raccontare.md`.

## 5. Come si scrivono le parole straniere

- **Invariabili al plurale.** I film, i computer, gli sport, i manager, le email, i fan, i bar. Mai «i films», «i fans».
- **Genere.** Segue di solito il traducente o l'uso: la mail, la password, la privacy, la newsletter, la call, la chat, la startup; il weekend, il feedback, il link, il brand, il web, il marketing, lo smartphone, lo streaming, lo spam. In caso di dubbio guarda un dizionario recente.
- **Articolo.** Si sceglie in base al suono: lo show, lo staff, lo chef, lo yogurt, lo humour, l'hotel, l'hobby, il weekend, il whisky, il web, lo swing, il jazz, il jet.
- **Corsivo.** Solo per parole straniere non acclimatate. Computer, sport e weekend non lo vogliono.
- **Nomi propri.** Scrivili esatti, accenti compresi. Le città con un nome italiano tradizionale lo usano: Londra, Parigi, Monaco, Mosca, Pechino, Nuova Delhi, L'Aia, Francoforte. New York resta New York.

## 6. Formule di cortesia e di servizio

Le interfacce e le email tradotte dall'inglese hanno un'aria riconoscibile. L'italiano è più asciutto e meno espansivo.

| Calco | In italiano |
| --- | --- |
| Per favore inserisci la tua password | Inserisci la password |
| Per favore nota che | Nota: / Attenzione: |
| Sei sicuro di voler eliminare? | Vuoi eliminare il file? / Confermi di voler eliminare il file? |
| Ops! Qualcosa è andato storto | Che cosa è successo e che cosa fare: «Non siamo riusciti a salvare. Riprova» |
| Siamo spiacenti per l'inconveniente | Ci scusiamo per il disagio |
| Grazie per la tua pazienza | Grazie dell'attesa / Grazie per la pazienza |
| Grazie per averci contattato | Grazie per averci scritto / Grazie del messaggio |
| Apprezziamo il tuo feedback | Grazie per il tuo parere |
| Sei tutto pronto! | Fatto. / È tutto pronto |
| Congratulazioni! Ce l'hai fatta | Fatto. / Registrazione completata |
| Sei benvenuto (in risposta a grazie) | Prego / Figurati / Di niente |
| Scopri di più | va bene; anche Per saperne di più, Leggi tutto |
| Inizia ora, Inizia gratis | Comincia, Prova gratis |
| Unisciti a noi | Iscriviti, Vieni con noi |
| Resta sintonizzato, Restate con noi | Continua a seguirci, A presto, Ti terremo aggiornato |
| Non potremmo essere più felici, Non potevamo essere più contenti | Siamo felici di, Siamo contenti di |
| Siamo entusiasti di annunciare che | Siamo felici di condividere questa novità; in un articolo o in una lettera, la notizia senza annuncio |
| Abbiamo ricevuto la tua richiesta e ti risponderemo il prima possibile | Va bene così. Se c'è un tempo vero, meglio dirlo: «Ti risponderemo entro due giorni» |
| Buona giornata! (a chiusura di ogni email) | Cordiali saluti / Un saluto / A presto, secondo il registro |

Le formule che le interfacce italiane usano davvero, contate su quindicimila stringhe, sono in `microcopy.md`. Tre abitudini inglesi da lasciare cadere: ringraziare in ogni frase, scusarsi in ogni frase, congratularsi con l'utente perché ha compilato un modulo.
